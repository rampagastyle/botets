# VideoProcessing v14

Telegram-бот для нарезки видео в вертикальный 9:16 формат.

## Что нового

- 480p / 720p / 1080p, максимум 1080×1920.
- Мягкий blur вместо чёрных полей.
- Водяной знак снизу по центру: `/watermark текст`.
- Удаление водяного знака: `/watermark off`.
- Автоматические субтитры:
  - `source` — берёт готовые/автоматические субтитры из источника, почти без CPU.
  - `ai` — опциональная транскрипция через OpenAI API; локальный Railway почти не занимается распознаванием.
  - `off` — выключено.
- Язык интерфейса и субтитров: `ru` / `en`.
- Исправлена кнопка «О проекте».
- Один тяжёлый job одновременно: глобальный semaphore = 1.
- FFmpeg: 1 поток, ultrafast, временные файлы удаляются после каждого этапа.
- Водяной знак + субтитры + вертикальный фон + баннер объединены в один encode для уменьшения нагрузки.
- Исходник ограничен 512 МБ по умолчанию.

## Команды

- `/start`, `/help`
- `/settings`
- `/quality 480|720|1080`
- `/clip 15|30|45|60`
- `/watermark текст`
- `/watermark off`
- `/subtitles off|source|ai`
- `/language ru|en`
- `/banner`
- `/mirror`
- `/caption текст`
- `/sendall`
- `/last`
- `/cleanup`

## Низкая нагрузка

По умолчанию субтитры работают через `source`: если площадка отдаёт VTT, бот просто скачивает маленький текстовый файл и встраивает его во время основного кодирования. Локальная модель Whisper не запускается.

Для полноценного распознавания речи без нагрузки на Railway можно включить `ai` и задать `OPENAI_API_KEY`. Используется модель транскрибации `gpt-4o-mini-transcribe` по умолчанию; её можно заменить через `OPENAI_TRANSCRIBE_MODEL`.

## Переменные окружения

```env
BOT_TOKEN=...
ADMIN_IDS=123456789
WHITELIST=123456789
OPENAI_API_KEY=...
OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
MAX_FILE_SIZE=536870912
```

`OPENAI_API_KEY` не обязателен, если используются субтитры `source`.
